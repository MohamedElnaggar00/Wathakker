## 🌙 نظرة عامة

«وذكر» تطبيق أندرويد مفتوح المصدر يجمع بين أدوات المسلم اليومية في مكان واحد: مواقيت الصلاة بدقة حسابية عالية، تنبيهات قابلة للتخصيص لكل صلاة على حدة، أذكار الصباح والمساء وحصن المسلم، مسبحة إلكترونية، وبوصلة قبلة — كل ذلك بتصميم عربي أصيل يدعم الكتابة من اليمين إلى اليسار بشكل كامل، وبإحدى عشرة لغة للواجهة.

## ✨ الميزات الرئيسية

| القسم | الميزات |
|---|---|
| 🕌 **مواقيت الصلاة** | تحديد الموقع تلقائيًا عبر GPS أو يدويًا باختيار الدولة والمدينة، ثماني طرق حساب معتمدة (الهيئة المصرية العامة للمساحة، أم القرى، رابطة العالم الإسلامي، أمريكا الشمالية ISNA، جامعة كراتشي، الكويت، قطر، دبي)، اختيار المذهب الفقهي لحساب العصر (شافعي أو حنفي)، قواعد خطوط العرض العالية، وتعديل يدوي بالدقائق لكل صلاة على حدة مع تعديل التاريخ الهجري. |
| 🔔 **تنبيهات الصلاة** | جرس مستقل لكل صلاة من الصلوات الست (بما فيها الشروق) يصلك كإشعار، توقيت مرن بدقة دقيقة واحدة (عند الأذان أو قبله بعدد من الدقائق تكتبه أو تختاره بالسحب)، **إشعار تذكير الإقامة** بفواصل مضبوطة لكل صلاة (الفجر ٢٥ دقيقة، الظهر والعصر والعشاء ٢٠ دقيقة، المغرب ١٠ دقائق)، **وضع عدم الإزعاج التلقائي** بين الأذان والإقامة، وإعدادات مشتركة لنغمة الإشعار والاهتزاز. |
| 🧭 **اتجاه القبلة** | بوصلة أنيقة تتبع مظهر النظام فاتحًا أو داكنًا: قرص مدرّج بعلامات دقيقة وأرقام كل ٣٠ درجة يدور بسلاسة مع اتجاه الهاتف، أسماء الاتجاهات بالعربية (شمال/شرق/جنوب/غرب)، قراءة رقمية كبيرة للدرجة واسم الاتجاه، علامة كعبة مميزة عند زاوية القبلة تتحول إلى الأخضر مع اهتزاز تأكيدي عند الانحراف أقل من ٣ درجات، تصحيح الانحراف المغناطيسي بحسب الموقع (الشمال الحقيقي)، وتنبيه لمعايرة المستشعر عند ضعف الدقة. |
| 🕰️ **مواقيت إضافية** | صفوف اختيارية في شاشة الصلاة: الإمساك (قبل الفجر بعشر دقائق)، الضحى، منتصف الليل، وقيام الليل (بداية الثلث الأخير) — تُفعَّل من الإعدادات بحسب الحاجة. |
| 📅 **محوّل التاريخ** | تحويل فوري بين التاريخ الهجري والميلادي في الاتجاهين، وفق تقويم أم القرى، مع عرض اليوم الأسبوعي. |
| 📿 **الأذكار وحصن المسلم** | مكتبة أذكار كاملة من حصن المسلم مرتبة في فصول، إضافة أذكار خاصة وتنظيمها بتصنيفات ملوّنة، أذكار مفضلة، تذكيرات بأوقات مخصصة، وأدعية نبوية مضافة مسبقًا. |
| 📊 **الإحصائيات** | متابعة الالتزام اليومي: عدد الأذكار المقروءة اليوم وهذا الأسبوع وهذا الشهر، وسلسلة الأيام المتتالية (Streak). |
| 🔢 **المسبحة** | عدّاد تسبيح يحفظ تقدّمك حتى بعد إغلاق التطبيق. |
| 📱 **ودجت شاشة القفل** | ودجت قابلة للتخصيص بالكامل (الألوان، الخلفية، النص) تعرض المواقيت على شاشة القفل. |
| 🎨 **التخصيص** | إحدى عشرة لغة للواجهة مع دعم كامل للاتجاهين RTL وLTR، وضع فاتح وداكن وتلقائي، وخطوط عربية متعددة (القاهرة، النسخ، الأميري، الرقعة). |

<details>
<summary><b>🔔 تفاصيل إضافية عن نظام التنبيهات</b></summary>

- تُجدول إشعارات التنبيه بدقة (Exact Alarms) وتُعاد جدولتها تلقائيًا بعد إعادة تشغيل الجهاز.
- لكل صلاة نافذة إعداد مستقلة بالضغط المطوّل على جرسها: التوقيت بدقة دقيقة واحدة، إشعار الإقامة، وعدم الإزعاج التلقائي.
- عند عدم منح إذن الوصول إلى وضع عدم الإزعاج، يوجّهك التطبيق إلى شاشة الإذن في النظام بدلًا من تفعيل شكلي لا يعمل.

</details>

## 🆕 ما الجديد في الإصدار 3.1.0

- دمج كامل لنظام التنبيهات: أجراس على الصلوات الست مع تذكير الإقامة وعدم الإزعاج التلقائي.
- شاشة «الموقع والحساب» الجديدة: الموقع، طريقة الحساب، المذهب، وتعديلات الدقائق في مكان واحد مع إعادة حساب فورية.
- بوصلة القبلة بتصميم جديد كليًا.
- المواقيت الإضافية: الإمساك والضحى ومنتصف الليل وقيام الليل.
- محوّل التاريخ الهجري ↔ الميلادي.
- مراجعة لغوية كاملة للواجهة الإنجليزية وتعريب عناصر الودجت.

## 🛠️ التقنيات المستخدمة

- **اللغة**: Kotlin
- **الواجهة**: Jetpack Compose مع Material 3 وتصميم مخصص مستوحى من One UI
- **قاعدة البيانات**: Room لتخزين الأذكار والتصنيفات والإحصائيات محليًا
- **حساب المواقيت**: مكتبة حساب فلكية مع تقويم أم القرى للتاريخ الهجري
- **المعمارية**: MVVM
- **الإشعارات**: Exact Alarms مع Broadcast Receivers لإعادة الجدولة بعد إقلاع الجهاز

## 🔨 البناء من المصدر

```bash
git clone https://github.com/MohamedElnaggar00/Wathakker.git
cd Wathakker
./gradlew assembleDebug
```

ينتج ملف APK في `app/build/outputs/apk/debug/`. يتطلب البناء JDK 17 وAndroid SDK.
