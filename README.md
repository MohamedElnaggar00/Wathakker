# تطبيق وَذكِّر

**وَذكِّر** هو تطبيق إسلامي مبسط يهدف إلى مساعدة المسلم في الحفاظ على أذكاره اليومية وتنبيهاته بطريقة عصرية وسهلة الاستخدام.

## مميزات التطبيق

1. **إدارة الأذكار والتنبيهات**: 
   - يمكنك إضافة الأذكار، وتعديل نصوصها.
   - تخصيص أوقات التنبيه لكل ذكر بشكل منفصل، مع واجهة منتقي الوقت السلسة.
   - التحكم في تفعيل وإلغاء التنبيهات بضغطة زر.
   - حذف الأذكار التي لا ترغب فيها.

2. **قائمة الأذكار المفضلة**:
   - إمكانية تمييز أذكار معينة لتصل إليها بسرعة عبر قسم "الأذكار المفضلة".

3. **عداد التسبيح**:
   - مسبحة إلكترونية بسيطة، تقوم بحفظ عدد التسبيحات حتى بعد إغلاق التطبيق.

4. **لوحة التحكم (الشاشة الرئيسية)**:
   - تعرض التنبيه الحالي والتذكير القادم بناءً على الأذكار المفعلة لتبقى على اطلاع دائم.

5. **واجهة مستخدم عصرية**:
   - تصميم من اليمين إلى اليسار (RTL) لدعم اللغة العربية بشكل مثالي.
   - متوافق تمامًا مع كل من الوضع الفاتح (Light Mode) والوضع الداكن (Dark Mode).
